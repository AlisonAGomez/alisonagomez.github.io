# Portfólio Alison Guilherme

Site pessoal de Alison Guilherme de Almeida Gomez, com apresentação, projetos, experiência em TI, laboratório, competências e formação.

O site utiliza HTML, CSS e JavaScript, com publicação pelo GitHub Pages.

## Desenvolvimento local

```powershell
py -3.10 -m http.server 8132 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8132`.

## Verificações

```powershell
py -3.10 tests/validate_v4.py
node --check site.js
```

O CSS da V4 está em `v4.css`. O arquivo `style.css` da versão anterior continua disponível para as páginas históricas de estudos de caso, que permanecem acessíveis.

Conteúdos técnicos anteriores são mantidos como registro histórico e não substituem a atualização das páginas atuais. Não publicar credenciais, dados reais de clientes nem evidências sem revisão.
